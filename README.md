# tess-cases-guias

Passo a passo dos Human AIs individuais da página de cases da Tess (cases.tess.page), um arquivo por Human AI e idioma.
A página busca estes arquivos sob demanda pelo jsDelivr. Empresas, pessoas e números das amostras são fictícios.

Step-by-step guides for the individual Human AIs on the Tess cases page, one file per Human AI and language, loaded on demand through jsDelivr. Companies, people and numbers in the samples are fictional.
